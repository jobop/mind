    新建个人项目

    新项目拥有独立的导图和 Skill 库。可以在项目设置中添加多个方法，Agent 会按任务选择。

    项目设置与 Skill 库

    勾选启用多个 Skill。每次生成时，Agent 检索此项目的目录、选择并读取相关方法；这些 Skill 对其他项目不可见。

    添加内置方法

    Skill 是方法指导文本，不会执行其中的脚本。启用 / 移除操作自动保存；项目名称和背景点击下方保存。

    编辑节点

    参考资源

    仓库、图片、视频或网页，供当前节点及相关分支参考。

    连接你的模型

    填写 OpenAI 兼容接口，验证成功后就可以展开思考。连接测试会发送一条简短请求，可能消耗少量模型额度。

    尚未连接模型

    仅在模型支持视觉时启用；读取的图片会发送至你配置的模型服务。

    输出预算

    这是平台请求的输出预算，并非模型上下文容量或 SSE 传输大小。默认 8192，请按服务商支持的范围调整；预算越高，单次调用可能输出更多内容。

    Key 经本站服务端加密，保存在当前浏览器的安全 Cookie 中，7 天后过期；不会写入导图或以明文保存在网页中。更换接口地址需重新输入 Key。导图与 Skill 库保存到你的个人项目，生成时向你配置的模型发送当前任务所需的内容。模型连接仅当前账号、当前浏览器可用。

    删除这张导图？

    导图将从当前项目移除。删除后可以点击画布工具栏的「撤销」恢复，也可以先导出备份。

    方法论与项目背景

    Skill 是生成时采用的领域分析方法。可选用内置框架、修改为自己的规则，或导入 SKILL.md；只读取文本，不执行文件中的命令或工具。

    Skill 保存到当前个人项目，同项目内所有导图共用；Agent 按节点任务选择相关方法，其他项目不可见。自定义方法论和导入文本不能保证事实准确，重要结论仍需核实。

    腾讯 SkillHub

    搜索公开 Skill，预览后选取 Markdown 文档导入。只加载分析指导文本，不执行脚本或安装依赖。

    查看 SkillHub 原页面 ↗

    请选择主文档，按需添加参考文件（最多 4 个）。导入后的总正文需不超过 12000 字符。依赖工具或执行环境的 Skill 不会仅靠导入文本获得那些能力。

    让想法长出分支

    ① 点击任意节点，在右侧选择「深入提问」或「寻找方案」，生成下一级分支。

    ② 右键节点（手机长按）打开操作菜单，可生成问题/方案、添加、编辑、折叠或删除。双击节点也可编辑；右键画布可居中、撤销或新建导图。

    ③ 单指拖动画布移动，双指张开放大、合拢缩小，也可使用右下角按钮缩放，点击「⛶」查看整张导图。

    ④ 注册或登录个人账号，可创建多个项目；每个项目包含独立导图与 Skill 库，自动保存到服务器。旧版浏览器导图可用「迁移旧版浏览器导图」迁入新项目，原件保留。

    ⑤ 在「项目 Skill 库」添加多个内置方法、Markdown 或腾讯 SkillHub 方法。勾选启用后，Agent 会检索当前项目的 Skill 目录，按任务选择并实际读取；执行记录展示本次采用的方法。
    ⑥ 点击「模型设置」填写兼容接口地址、模型名和 API Key，再点「连接并验证」。所有新分支均由你连接的真实模型生成；失败可重试，生成中可取消。Pi Agent 会读取上下文与 Skill、按需调用工具、校验并提交结果；任务步骤会显示在执行记录中。
