枝想 2.0 · Pi Agent 思维导图

运行环境：Node.js 22.19 或更新的 LTS 版本（https://nodejs.org/）。

1. 完整解压 ZIP，不要直接在压缩包中运行。
2. Windows 双击「启动-Windows.bat」；Mac 双击「启动-Mac.command」。
   也可在本目录运行 npm start。
3. 浏览器打开 http://localhost:3000，保持启动窗口开启。
4. 模型设置中填写 Base URL、模型 ID、API Key；必须支持 Function Calling 和 SSE 流式响应。
5. 点击连接并验证，实际通过工具能力检测后开始使用。
6. 选择领域 Skill、补充背景，再点击节点或右键生成问题/方案。

完整运行包自带 Pi JavaScript 依赖，不必手动 npm install。源码包会在首次启动时按锁定版本安装依赖；需要 npm 网络可用。

现在的生成由真正的 Pi Agent SDK 驱动：
制定计划 → 读取节点与 Skill → 按需调用工具 → 校验/修订 → 提交分支。
界面会实时显示任务步骤、模型轮次、工具状态与公开来源。
每次任务最多 8 次模型请求、20 次工具、5 个网页、180 秒；会消耗对应模型额度。
取消或失败不会写入候选节点。普通一次请求和演示生成均不作降级。

Agent 工具包括腾讯 SkillHub 搜索/读取、公开 HTTPS 文本网页读取和分支校验。
没有通用搜索引擎、登录态浏览器、Shell 或任意代码执行。
依赖未接入工具的 Skill 不能仅靠导入就完整执行；应用不会安装或运行 Skill 中的脚本。
可在背景或备注中加入希望核实的公开来源 URL。

右键节点可生成、编辑、添加、折叠和删除分支；手机长按；右键画布可居中、撤销和新建。
Skill 设置中可打开腾讯 SkillHub，搜索并预览导入 SKILL.md 和参考文档。

升级：先导出 JSON 备份，替换程序文件时保留原 .branch-data 文件夹。
继续使用同一浏览器与 http://localhost:3000，可保留原导图和连接。
旧模型连接建议重新验证工具能力。不要清除浏览器站点数据，不要分享运行后的 .branch-data 目录。

重要边界：结构与引用检查不代表事实正确。无外部证据时会注明依据为用户材料与 Skill；重要结论需进一步核实。

源码、依赖版本、工具边界与测试说明见 README.md。
